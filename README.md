# Interactive Quiz Application

An interactive quiz website built using HTML, CSS, and JavaScript. It allows users to answer questions, check their score, and interact with a simple quiz interface.

## Features

- Displays quiz questions with answer options.
- Calculates the score based on correct answers.
- Provides a final score after completing the quiz.
- Includes a theme toggle to switch between light and dark modes.
- Prevents the same correct answer from being counted multiple times.

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start answering the quiz questions.

## Live Demo

[Play the Quiz](https://quiz-rose-eight-33.vercel.app/)

## Project Structure

- `index.html` — Defines the structure of the quiz webpage.
- `style.css` — Contains the styling and themes.
- `script.js` — Handles quiz interactions and scoring.

## Current Limitations

- The quiz runs in the browser.
- The questions and answers need to be updated in the source code to change the quiz content.
- Quiz scores are not stored in a permanent database.

## Conclusion

This project demonstrates the use of HTML, CSS, and JavaScript to build an interactive quiz application with scoring and theme-switching functionality.
